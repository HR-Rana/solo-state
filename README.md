# Solo State Homepage

Responsive luxury men's fashion homepage built with Next.js, TypeScript and Tailwind CSS v4.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Sections

Navbar, hero campaign, trust/service bar, categories, signature collection, new arrivals, best sellers, why Solo State, reviews, brand story, social proof, newsletter, FAQ and footer.

All visual assets are local SVG files in `public/images`, so the homepage does not depend on an image CDN. Replace these demo assets with Solo State product/campaign photos when ready.
